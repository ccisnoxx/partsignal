## 关键测试

- 直接 API 和并发请求均拒绝跨平台账号。
- 首次 `VERIFIED` 自动完成任务，重复验证不重复审计或转换。
- 在途发布存在时不能取消任务。
- 发布失效不回退任务，只创建一个 OPEN 待办。
- 创建修复任务不关闭待办；空处置说明不能解决。
- 事实退役、平台规则切换和并发候选变化会阻止修复任务创建。
- 历史检查输出稳定 ID，未清零时迁移/上线失败。

## 回滚点

- 历史检查失败立即停止，不执行约束迁移。
- 自动完成事务出现不一致时停止发布写入，不用补偿脚本猜测状态。
- 修复上下文出现版本漂移时停止修复任务创建，保留异常待办为 OPEN。

## Goal 2 验证证据

- OpenAPI、FastAPI 运行时 Schema 与前端冻结生成类型一致，人工完成任务入口已从契约和调用面删除。
- `0013_publication_closure` 升降级与前置门禁测试通过；数据库拒绝非终态跨平台发布、非法待办初始状态、绕过 revision 的解决和待办删除。
- PostgreSQL 集成测试证明并发 `VERIFIED` 仅转换一次任务 revision，并发发布失效只创建一个待办；追加式 `VERIFIED` 事件使合法的后续失效历史可通过 preflight。
- 当前本地数据执行 `preflight-integrity` 输出 `[]`；生产或预发布目标环境仍必须在部署前单独运行并人工处置，因此对应清单保持未完成。
- 最终验证通过：62 个后端单元测试、17 个 PostgreSQL 集成测试、8 个前端组件测试、2 个全 UI Playwright E2E，以及前后端 Docker 构建。
