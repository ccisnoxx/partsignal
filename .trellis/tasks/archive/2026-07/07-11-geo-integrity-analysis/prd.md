# GEO 数据完整性与人工文章观测闭环

## Goal

把 GEO 观测改为可复核的人工产品搜索记录：运营人员在豆包、DeepSeek、元宝等网站手动搜索一个产品后，登记真实搜索条件、结果截图，并对该产品每篇当前已发布文章明确标记“已推荐”或“未推荐”，为后续按产品、平台和文章分析优化提供可信历史。

## Background

- 当前弹窗同时要求目标问题和产品，且展示“启用联网搜索”、观测级推荐、准确性和引用等模型测试字段（`frontend/src/features/geo-observations/GeoObservationsPage.tsx:119`）。这些字段不能表达一个产品多篇文章分别是否被推荐。
- 当前前端提交只调用 `POST /api/v1/geo-observations`，没有调用模型或联网搜索；`web_search_enabled` 只是持久化布尔值（`backend/app/services/geo_observation.py:69`）。
- 产品的已发布文章已有唯一权威链路：`Product <- ContentTask <- ContentVersion <- PublicationRecord`；公开链接以不可变发布记录的 `final_url` 为准，不应在 GEO 中重复录入（`backend/app/models/publication.py:38`）。
- 已验证的搜索结果截图已可通过 `FileRecord(category=OPERATION_SCREENSHOT)` 和 `GeoObservationAttachment` 追加关联（`backend/app/models/geo_files.py:85`）。
- 弹窗滚动时标题悬浮由全局 `.ant-modal-header { position: sticky }` 导致（`frontend/src/styles/global.css:205`）。
- 历史 GEO 观测是追加式记录，不能删除、改写或猜测迁移为新的文章推荐结果（`contracts/database.md` 的 `0007 GEO Observation` 契约）。

## Requirements

### R1 弹窗滚动

- 弹窗标题随内容自然滚出视口，不覆盖下方字段。
- 保留 Ant Design Modal 自身的焦点圈定、键盘关闭和可访问语义，不实现第二套弹窗。

### R2 人工产品搜索登记

- 新登记只选择一个产品，不再选择目标问题。
- 记录人工访问的搜索平台、实际搜索词、观测时间和可选备注；搜索平台允许自由填写，以支持豆包、DeepSeek、元宝及后续网站。
- 页面和服务端不得调用 AI 模型、AI 渠道或联网搜索接口，也不再提交 `web_search_enabled`。

### R3 产品文章候选

- 产品选择后，服务端返回该产品当前状态为 `PUBLISHED` 或 `VERIFIED` 且具有 `final_url` 的全部发布记录。
- 候选项展示文章标题、发布平台和权威文章链接；链接直接来自 `PublicationRecord.final_url`。
- 产品没有可观测文章时禁止提交，并明确提示先完成发布登记。

### R4 逐篇推荐结果

- 每篇候选文章必须且只能登记一个结果：`RECOMMENDED`（已推荐）或 `NOT_RECOMMENDED`（未推荐）。
- 一次提交必须覆盖产品在提交事务中全部当前候选文章，避免漏标文章导致虚假的推荐率。
- 服务端校验文章属于所选产品、状态可观测、链接存在且集合完整；候选集合在填写期间变化时拒绝提交并要求刷新。

### R5 搜索结果截图

- 每次新观测至少关联一张已验证的 `OPERATION_SCREENSHOT`，允许多张。
- 缺失、未验证、类别错误或重复的附件均由服务端拒绝；前端提示截图是必填证据。

### R6 追加历史与更正

- 新观测不可原地修改；更正继续通过 `supersedes_id` 追加记录。
- 新更正必须与来源记录同属一个产品且均为人工文章观测，并重新提交当时完整的文章结果和截图。
- 历史模型结果观测继续只读、可列出和可追溯；不得把旧的发布关联猜测为“已推荐”或“未推荐”。

### R7 分析口径

- 人工观测指标从当前有效人工观测及其逐篇结果实时计算，不持久化汇总。
- 至少提供人工观测数、文章结果数、已推荐文章数、未推荐文章数和文章推荐率；没有文章结果时推荐率为 `null`，不伪装为 0%。
- 历史模型测试指标继续只服务旧记录兼容，不进入新的文章推荐率。

## Acceptance Criteria

- [x] 滚动登记弹窗时，“登记 GEO 观测”标题不再悬浮覆盖表单。
- [x] 新表单没有目标问题、联网搜索开关、观测级推荐、准确性和引用字段；选择产品后才加载文章候选。
- [x] 浏览器和服务端在登记过程中不调用任何模型或搜索供应商接口。
- [x] 产品的每篇当前可观测文章都展示权威标题、平台和链接，并可二态标记。
- [x] 漏标、重复、跨产品、低状态、无最终链接或候选集合已变化的文章提交均被服务端拒绝。
- [x] 没有至少一张已验证搜索结果截图时提交失败，非截图类别附件也失败。
- [x] 成功登记后列表能读取搜索平台、搜索词、截图关联及每篇文章结果，指标可由明细复算。
- [x] 历史模型观测仍可读取，旧关联保持未评估语义且不污染新推荐率。
- [x] OpenAPI、Pydantic、前端生成类型、数据库契约和迁移保持一致。

## Out of Scope

- 自动登录或抓取豆包、DeepSeek、元宝等第三方网站。
- 调用模型联网搜索、自动判断推荐结果、OCR 或截图内容解析。
- 新建独立 Article 模型、重复保存发布链接，或建立固定搜索平台枚举/配置中心。
- 综合 GEO 评分、排名算法、趋势图和优化建议生成；本任务先保证可分析的可信原始事实。

## Dependencies

- 复用现有产品、内容版本、发布记录和文件上传契约。
- 发布状态与 `final_url` 以已实现的发布闭环为准；GEO 不维护第二份发布状态或文章链接。
