# ADR-004：核心版不提供不可解释的统一 GEO 总分

- 状态：Accepted
- 日期：2026-10-01
- 接受日期：2026-10-01
- 接受依据：用户在本会话明确接受本 ADR 及 GEO-002 评审修订。
- 适用范围：GEO 核心版指标、仪表盘、管理摘要、机会规则、复测与报告；具体指标公式须按已接受的修订统一，旧文章关系口径保持独立。

## 背景

可见率、推荐率、引用、事实准确性、稳定性和数据质量具有不同业务含义。简单加权总分会隐藏分母、采集方式和严重错误。

## 决策

核心版只提供可拆解指标及分子、分母、样本等级、排除原因和明细下钻。不默认计算统一 0–100 GEO 分数。

可以提供管理摘要，但不得把多种指标压缩为不透明单值。

## 原因

- 电子元器件领域准确性风险高；
- 不同平台和问题不可简单混合；
- 样本不足时总分容易误导；
- 内部运营需要行动依据，不是营销评分。

## 后果

- 页面需要解释多个指标；
- 管理报告不能只显示一个数字；
- 机会规则直接基于明确指标；
- 后续如引入综合指数，必须新增 ADR、公开公式并保留组成项。

## GEO-002 评审修订（已接受）

- 接受结论：用户接受“不提供不透明统一总分”的原则及以下评审修订；具体指标公式仍需按修订要求在对应合同任务中统一。
- PRD 与指标文档的首位推荐率、严重错误运行率及运行成功率分母需要产品裁决。指标字典须统一 metric_code、统计单位、资格/排除规则、分母和 formula_version，避免相同名称返回不同含义。
- 分析成功率不得用可多次追加的成功 AnalysisRevision 数除以回答运行数。可选运行级覆盖率或分析尝试级成功率，但需各有明确名称、分母及版本。
- 新回答级指标与旧文章关系指标分别展示；未知值不补零，环境、重复采样和重试口径必须可解释。
- 详细依据、示例及备选方案见 [GEO-002 架构评审记录](./GEO-002-architecture-review.md)。

## GEO-601 分母裁决（2026-10-03）

用户在本任务会话明确裁决“两个都采用指标方法口径”：首位推荐率分母为存在可靠推荐顺序的推荐适用合格运行；严重错误运行率分母为存在可判断声明的合格运行。PRD §12.2与指标字典据此同步。无排序、只有UNJUDGEABLE声明的运行分别排除，不填0。运行成功率及分析成功率的未决口径不由GEO-601实施或裁决。


## GEO-602 数据质量口径裁决（2026-10-03）

本会话用户明确选择：

- 运行成功率采用方法口径，分母为 COMPLETED、FAILED、CANCELLED 终态运行；PENDING等未终态不进入分母。既有独立BUDGET_BLOCKED保留状态计数，不猜成FAILED或擅自加入用户选定的三态分母。
- 分析质量采用运行级分析覆盖率：有成功 current analysis 的已采集 Run / 全部已采集 Run。成功revision数不是分子；已采集由非空原始Answer证明，不按会推进的COLLECTED状态计数。

两个选择已同步PRD与方法字典，公共code为run_success_rate、analysis_run_coverage，版本geo-overview-quality-v1。Overview对latest attempt和current pointer一致读取；重分析不使覆盖率超过100%。复核与证据资格单独显示，不把分析覆盖误称为业务指标资格。历史评审冲突记录保留；分析尝试级成功率未在本任务实现。
