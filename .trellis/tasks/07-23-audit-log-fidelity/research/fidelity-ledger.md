## Browser 与交互账本

1. Browser 真实加载 `/audit`，页面标题为 `PartSignal · GEO 内容运营`，DOM 含筛选、列表和真实记录，无框架错误覆盖。
2. Browser 组合选择操作者、业务模块、动作、对象类型、执行结果，并输入请求 ID 与关键字；URL 同步得到全部服务端参数，结果收敛为唯一真实 `DENIED` 记录。
3. Browser 验证重置、手动刷新、自动刷新开关、详情打开/关闭，以及关联对象已删除时的明确说明。
4. 首轮 Browser/Playwright 均发现粘性表头拦截查看按钮；移除页面级 sticky 后，两者均可点击并加载真实详情。
5. Browser 固定视口为 `1280 × 720`，无法设置附件尺寸；按用户允许的回退条件，精确 `1581 × 995` 截图、跳页、错误态和移动端由项目已安装的 Playwright 补验。
6. 干净 Browser 标签页控制台无 `error` 或 `warn`；精确 Playwright 验收仅记录预期的登录前 `401` 和主动构造错误态的 `503`，无 `pageerror`。
