# CORE-01 运行详情可解释与可操作

用户已授权本地实现；不操作线上、不暂存提交推送，仅必要定向验证。

## 范围

- 运行详情替换 data_quality 占位，展示当前有效分析、复核、证据、费用/来源版本未知与通用指标资格。
- 使用 Overview/Answer Insights 相同输入转换、metric_eligibility 和已有指标集合，按冻结对象列出各指标附加排除原因。
- 服务端从真实 Run 来源、复测基线/请求生成后续导航；被替代尝试不导航为当前统计样本。
- 前端消费生成协议，不重算资格、公式或分母；不新增写命令。

## 完成条件

- 缺回答/未分析/待复核/合格/指标专项排除/历史替代/FAILED 重分析的说明准确。
- 机会与复测仅来自真实关联；洞察显式带时间范围和冻结问题与配置。
- 单次 REPEATABLE READ 保持一致；无迁移、外发、生产修改。
- 合同/生成类型检查、前后端定向测试与实际导航覆盖；保留原浏览器上传验收缺口及原外部等待任务。
