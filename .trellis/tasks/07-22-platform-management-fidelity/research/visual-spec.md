# 原型视觉规格

## 证据

- 批准原型：`../artifacts/platform-management-prototype-1581x995.png`
- 原始尺寸：1581×995。
- 当前 Browser 基线：`../artifacts/current-platforms-1581x995.png`。

## 页面网格

- 左侧固定导航约 190px；顶部栏约 64px 高。
- 主内容从 x≈190 开始；详情打开时主区约 1075px，右侧详情约 315px。
- 详情面板从 y≈135 延伸至底部，正文独立滚动；底部操作区固定。
- 页面背景为近白的淡蓝紫渐变；表面为白色/半透明白，细边框和极轻阴影。

## 主要尺寸与密度

- 标题区约 y=58–140；标题 24px、说明 14px，右侧新增按钮约 100×32。
- 五张统计卡等宽，高约 120px，间距约 14px，圆角约 9px。
- 筛选条高约 69px；搜索约 226×32，下拉约 124×32，重置约 64×32。
- 表头约 40px，数据行约 49–50px；原型首屏显示 10 行。
- 分页位于表格底部：左每页数量、中页码、右跳页。
- 详情分组标题约 14px/semibold，正文 13px，辅助标签 12px。

## 颜色与表面

- 主文字近 `#18233d`，次级近 `#68738b`，边框近 `#e8edf5`。
- 主按钮为蓝紫渐变；成功绿、缺 Prompt 橙、无有效规则红、停用灰均使用浅色背景状态标签。
- 卡片/详情为白色或轻透明表面，1px 边框，极轻投影；不得改成暖白或增加原型外装饰。

## 字体与图标

- 系统中文字体栈，接近 PingFang SC/Inter。
- 标题 24px；统计数值约 26–28px；卡片标题/正文 13–14px；辅助 12px。
- 导航、搜索、顶栏、操作使用统一线性图标；平台 Logo 使用真实彩色资产。
- 查看与更多为约 32×32 描边按钮，图标需保持相同描边、尺寸与基线。

## 交互状态

- 配置中心展开，平台管理选中；桌面可折叠，移动端沿现有 Drawer。
- 表格支持行悬浮；明确的查看按钮打开详情，不把整行变成第二个无障碍入口。
- 筛选、重置、分页、每页数量和跳页均有默认/悬浮/聚焦/禁用/加载状态。
- 详情选择与当前行同步；关闭后恢复主列表空间；长内容仅滚动详情正文。
- 危险操作继续使用确认流程，删除被阻断时展示服务端结构化原因。

## 首屏文案锁定

`PartSignal` → `配置中心 / 平台管理` → `平台治理` → `平台管理` → `管理具体内容平台、所属类型、官网、允许域名及配置完整性。` → `新增平台` → 五张统计卡 → 搜索与三个筛选 → `重置` → 当前总数 → `导出列表` → 表头 → 分页 → `平台详情` 及五个详情分组 → `编辑平台` / `停用平台` / `删除平台`。

原型数字、平台名称和趋势仅作为视觉示例，不是业务数据或种子要求。
