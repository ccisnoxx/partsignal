# 思考指南

这些指南只在变更出现对应风险时按需读取，不是每次开发的固定前置步骤。

| 指南 | 何时读取 |
|---|---|
| [代码复用](./code-reuse-thinking-guide.md) | 已看到重复实现，或共享常量、协议字段、配置键与公共 helper 的变更可能影响多个调用方 |
| [跨层数据流](./cross-layer-thinking-guide.md) | 数据跨越 API、服务、存储、Worker 或 UI 边界，且所有权、转换或失败语义尚不明确 |

审查结论必须回到实际数据来源、代码路径、合同和测试核实。没有校准证据时，不预设固定误报比例。局部值变更只搜索可能受影响的引用；共享常量、协议字段和跨调用方不变量才扩大搜索范围。

只有形成可复用的稳定项目知识时才更新本目录；一次性排障过程和通用工程常识不写入项目规范。
