# I02-3 验收设计

- `make verify` 是唯一顶层执行入口；其真实输出和退出码是仓库级门禁证据，不拆分替代。
- 门禁环境只覆盖宿主 PostgreSQL 测试连接和独占 Redis DB 14，避免 `.env` 中开发设置污染 production Settings 测试。
- 运行前后分别记录固定端口、Redis key 数、E2E 数据库、临时目录与两处工作树状态；只有本次运行前后差异才归于 I02-3。
- 门禁日志使用 `bash -o pipefail` 与 `tee` 保存；命令退出码不被日志管道覆盖。
- 独立复核仅在完整门禁通过、资源清理完成且候选代码输入未再变化后开始；复核代理只读，不执行 Git 写操作或文件修改。
- 任务内允许的写入只包括 Trellis 验收、复核和完成状态记录。若候选代码变化，当前完整门禁证据失效，后续完整复验留给新会话。
