# 当前实现与原型差异

## 当前 Browser 基线

- 视口：1581×995。
- 页面已真实加载，配置中心展开，`内容平台` 选中。
- 现有内容只有标题、新增按钮和全量平台表格；无控制台错误。
- 当前表格列为平台、slug、官网、允许域名、当前规则、Prompt、操作；分页由前端 Ant Table 对全量响应处理。

## 视觉差异

- 左侧栏当前约 228px，比原型约 190px 更宽；主内容相应更窄。
- 顶栏、标题区、按钮样式和背景色接近现有产品体系，但标题说明、导航文案与原型不同。
- 缺少五张统计卡和筛选条；表格直接占据首屏主体。
- 当前表格表头/行高接近原型密度，但列宽、列组成、分页位置和操作样式不同。
- 缺少右侧固定详情面板及底部操作区。

## 数据与功能差异

| 原型能力 | 当前状态 | 分类 |
|---|---|---|
| 平台总数/缺 Prompt/缺有效规则/配置完整 | 当前全量列表可推导，但无服务端统计契约 | 需后端统一投影 |
| 已启用平台/状态筛选/停用 | PlatformProfile 无状态 | 业务未知 + DB/API/权限 |
| 搜索、类型、完整性筛选 | 列表 API 无参数 | 需服务端查询 |
| 分页、每页数量、跳页 | 前端对全量集合分页 | 需服务端分页 |
| 导出当前结果 | 不存在 | 需同查询口径导出 |
| 类型名称 | 类型 API 已有，列表只显示关联 ID | 后端可投影或前端现有查询可展示；分页后优先后端投影 |
| 当前规则/Prompt | 已有 | 直接复用并补详情时间 |
| 账号总数/启停数 | 账号有 `is_active`，无聚合 | 后端已有数据、前端缺失 |
| 更新时间 | Profile 无时间字段；审计可追踪事件 | 需明确权威投影/可能 DB 字段 |
| 引用次数 | 已批准按引用平台任一规则版本的 ContentTask 唯一任务数统计 | 新增服务端聚合与任务列表平台筛选 |
| 详情面板 | 不存在 | 前端 + 聚合详情 API |
| 新增/编辑/删除 | 已存在 | 迭代现有实现 |
| 规则/Prompt 入口 | 已存在页面 | 增加当前平台 URL 定位 |
| 账号入口 | 账号位于业务设置，缺平台 URL 定位 | 最小扩展现页 |
| 引用分析入口 | 无明确目标页 | 口径批准后决定 |

## 可复用实现

- 现有 PlatformsPage 表单、mutation、query key 与平台 Logo 输入。
- AI 渠道列表已有服务端搜索、筛选、稳定排序、分页、统计 counts 模式，可复用结构而不抽象通用框架。
- 发布工作台已有服务端投影、周期窗口、账号活跃状态和平台关联查询。
- `TableRegion`、`PageHeader`、`AsyncState`、`DeletionError`、`StatusTag`、`PlatformAvatar` 和全局语义 Token。

## 当前契约缺口

- 平台列表响应只有 `items`，没有 `page/page_size/total/summary`。
- 平台 Profile 无 `is_active/status`、`created_at/updated_at`。
- 平台账号无更新/启停 API；本任务只需要摘要，除非状态语义另有批准。
- 平台详情和导出无 API；内容任务列表无 `platform_profile_id` 服务端筛选参数。
- 域名创建时服务会 `casefold().strip('.')`，更新时未复用；Schema 仅唯一/非空，不验证主机名。
- 删除约束以规则版本和账号为直接引用，历史通过下游 RESTRICT 继续保护；原型“历史引用”提示不能替代当前契约。
