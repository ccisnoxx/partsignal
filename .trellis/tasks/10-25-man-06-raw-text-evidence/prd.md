# MAN-06 原始文本证据的页面上传与关联

## 用户结果与已核对合同

人工录入可选择原始纯文本文件，完成可信上传后关联当前表单，查看/移除关联，随已有草稿保存和正式提交冻结。原始文件字节保持，不把文件内容填入回答或任意摘要，不自动宣称脱敏。

`geo_answer_files.py`/文件服务和数据库合同已有：EVIDENCE、text/plain、1..50MiB、VERIFIED、INTERNAL/RESTRICTED、当前上传者、实际对象HEAD size/hash/type重验，单个`raw_payload_file_id`且与截图ID不同。冻结require_screenshot=true仍要求截图，文本不能替代。原始摘要闭合且仅允许结构事实。

## 验收

- [x] 页面可上传text/plain文件，明确限制和敏感信息检查提示；错误类型、空文件、超限在intent前失败。
- [x] 原字节SHA/传输及intent/VERIFIED完整性检查通过后才替换关联，失败保留原ID与未保存回答。
- [x] 文本ID为RHF表单状态，默认恢复原ID，移除显式null，保存/提交用本地新值；冲突重读保留本地编辑，显式采用服务端才替换。
- [x] 未改文件时保留既有摘要；替换/移除不把旧文件摘要附到新关联，也不猜来源或完成原因。
- [x] 文本与截图独立上传，聚合阻塞防止保存/提交/无提示离开；一个完成不得解除另一个的阻塞。
- [x] 未知结果先读取原文件状态，complete/abort不盲重放、不重传字节；主体/Run/卸载隔离生效。
- [x] 定向验证、独立只读复核、任务及父清单/SOP同步完成，保留既有未提交和暂存内容。

## 操作边界

仅本地实现与必要定向验证，完成保持review，不等同部署或用户验收。MAN-01～05不重复实施，不接入浏览器自动化、不创建平台、不操作线上、不提交推送、不新增自动跟进、不重查OSS自然清理；保留`NOT_RUN_NO_EXISTING_PLATFORM`。
