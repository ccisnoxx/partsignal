# Catalog 使用指南：监测对象、竞品和身份字典

适用 R1 GEO-101～106 当前 Catalog。进入 **业务配置 → 监测对象与竞品**，路径 `/configuration/geo-entities`。管理员维护配置；ENGINEER 可通过页面链接搜索/查看，不能创建或修改。

Catalog 保存监测身份和用途说明。产品型号、品牌、类别及 Markdown 事实仍在产品工作区维护；建立监测身份或修改别名/域名不会改变已批准的 FactVersion 和审核历史。

## 从现有产品建立监测身份

1. 在「产品」工作区确认目标 Product；若尚未录入，使用既有「新建产品」流程。事实录入、提交和批准仍在该工作区完成。
2. 打开「监测对象与竞品」，点击「新建监测对象」，选择「自有产品」。
3. 在「搜索现有产品」输入型号/品牌，再从「现有产品」候选选择正确 Product。候选分页独立于对象列表，核对品牌和型号。
4. 可选择已建立的「自有品牌」作为父级品牌，也可留空。
5. 填写「监测说明」，只描述监测用途，例如“关注该型号的自然提及”，点击「创建监测对象」。
6. 详情显示当前产品身份（只读）、Revision、字典和删除条件。URL 的 `subject_id` 可复制或刷新恢复。

一个 Product 最多有一个**启用的**自有产品监测身份。重复创建返回 `GEO_SUBJECT_PRODUCT_EXISTS`，选择和说明保留，请查看已有对象。停用身份可保留，但有其他活动身份时不能重新启用；系统不承诺只有一个历史对象。

绑定和对象类型创建后不能修改，不提供独立名称覆盖。产品工作区更新当前品牌/型号时，Catalog 读取当前产品身份；已批准事实快照不会被改写。事实修订走产品事实流程。

## 创建竞品

1. 新建「竞品品牌」，填写规范名称、显示名称和说明。
2. 新建「竞品产品」，填写规范型号/名称和显示名称，可搜索并选择刚建立的竞品品牌作为父级。
3. 保存后核对详情的父级。竞品不绑定自有 Product，不会产生或修改产品事实。

「自有品牌」「竞品品牌」「参考型号」使用规范名称和显示名称。自有产品只能关联自有品牌；竞品产品只能关联竞品品牌。品牌及参考型号不能设置父级。

## 添加别名与域名

详情点击「新增别名」，填写文本、类型（名称/型号/缩写/历史名称）、可选语言标签及启停状态，点击「保存别名」。系统统一 Unicode/空白/大小写规范；同对象规范后的别名不能重复，停用别名也占用唯一性。跨对象相同别名允许保留，搜索可返回多个候选，不能据此断定唯一归属。

点击「新增域名」，只填写精确主机名，如 `brand.example.invalid`，选择自有/官方/分销商/其他关系，然后「保存域名」。不含协议、路径、端口、账号或通配符。Unicode 域名保存为小写 IDNA/Punycode。关系是人工配置，不是所有权证明；保存不执行 DNS、HTTP 或外部采集。修改域名须删除后重建。

## 查找、修改、停用和删除

- 当前可按名称、产品品牌/型号及别名搜索，按类型、启用状态、Product ID、父级 ID 筛选，分页/排序；筛选和选中详情保存在 URL。
- **当前限制**：搜索框包含“域名”，但后端尚未实现域名搜索条件；域名可在详情查看。请按名称/别名或 Product ID 查找。GEO-106 实际验证确认该缺口，本任务未扩展查询能力。
- 详情「更多操作」提供编辑/启停和服务端允许的删除。监测说明/字典修改只改变配置，产品事实不在该表单内。
- 直接引用显示删除阻断，不能以停用绕过。当前已接入子对象（包含停用）及 Product 监测引用的删除保护；未来计划/运行/分析/机会引用尚未交付，零计数不代表这些能力已实现。
- 关闭未保存编辑器或离开页面时处理放弃确认；取消确认保留输入。

## 错误与恢复

| 现象 | 处理 |
|---|---|
| 候选/列表读取失败 | 使用对应重试读取；已成功配置不要再次创建 |
| 重复产品/别名/域名（409） | 核对已有配置，保留输入并调整，不重复提交同值 |
| REVISION_CONFLICT | 本地输入保留；「加载最新版本并保留输入」后核对基线，再自行保存，无自动写入重放 |
| 删除引用阻断 | 按 blocker 处理引用；应保留的身份可停用，不能强删历史 |
| 登录过期/无权限 | 重新登录或由管理员维护；ENGINEER 无写入口且服务端拒绝写入 |

R1 Catalog 配置不启动观测/采集、不计算指标或评估机会。分析冻结字典等后续能力由 GEO-502/GEO-504 等任务交付。
