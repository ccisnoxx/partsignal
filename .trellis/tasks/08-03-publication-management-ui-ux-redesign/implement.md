```bash

  tests/e2e/mvp-flow.spec.ts \
  tests/e2e/cross-page-visual-convergence.spec.ts \
```

最终检查（2026-08-03）：定向组件 6/6、lint、typecheck、build 与 `git diff --check` 均通过；正式视觉资产由隔离真实 API 数据生成并登记在 `assets/approved/manifest.md`。
