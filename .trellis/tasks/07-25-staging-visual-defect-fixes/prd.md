# 修复线上视觉验收缺陷

## Goal

修复 AI 渠道表格列重叠、用户管理 375px 指标卡重叠及共享移动触控目标不足，并完成对应视觉回归。

## Background

- 父任务 `.trellis/tasks/07-25-post-deployment-visual-acceptance/` 已在 `main@bee2ef4` 的真实预发布环境复现三项缺陷。
- 唯一视觉规范是 `.trellis/spec/frontend/visual-system.md`；表格列宽、共享 `MetricTile` 和移动触控目标同时受 `.trellis/spec/frontend/component-guidelines.md` 与 `.trellis/spec/frontend/quality-guidelines.md` 约束。
- 本任务只修复已确认的前端视觉几何，不改变 API、数据库、权限、查询参数、业务状态、交互入口或发布流程。

## Requirements

### R1. AI 渠道表格列几何

- 在 `/configuration/ai/channels/:channelId`、1440×1000、340px 详情面板打开时，“测试状态”和固定“操作”列不得相交或互相遮挡。
- 保留渠道名称、启用状态、API 根地址、API Key、Header 数量、模型数量、测试状态和操作八类信息；保留固定操作列、现有直接操作、更多菜单、权限、确认和 API 载荷。
- 长文本列承担弹性宽度，状态、数量和操作列保持紧凑固定宽度；真实窄屏只能由 Ant Table 在 `TableRegion` 内横向滚动，不得制造页面级横向溢出。
- 固定列样式必须匹配项目锁定的 Ant Design 6 实际逻辑类名，不得用不透明遮罩、提高层级或隐藏测试状态掩盖列宽错误。

### R2. 共享指标卡窄屏净空

- `/users` 在 375×812 和 320px 代表宽度下，`MetricTile` 图标不得与标题、数值或辅助文字相交。
- 修复必须位于共享 `MetricTile` 移动样式所有者，保持用户页现有两列信息密度，不增加页面局部包装或复制指标卡实现。
- 同源的 `/configuration/platforms` 指标卡必须同步验证；Dashboard、内容任务和 GEO 观测等既有消费者不得回归。
- 1440px 桌面和真实 200% 缩放下的已批准指标层级保持不变。

### R3. 共享移动触控目标

- 在移动壳层断点内，导航按钮、主题按钮和默认 Ant Drawer 关闭按钮的可点击框宽高均不得小于 44 CSS px。
- 修复复用现有 991px 响应式边界，不提高全局桌面 `controlHeight`，不逐页面复制 Drawer 样式。
- 保留 280px 移动 Drawer、可访问名称、Escape 关闭、焦点圈定、触发器焦点恢复和 pathname 变化后的内容聚焦。
- `closable={false}` 且使用自定义关闭按钮的 Drawer 不在本任务范围内，除非真实验收另行证明同一缺陷。

### R4. 回归与视觉证据

- 使用真实浏览器几何断言验证元素矩形不相交、44px 触控目标、表格局部滚动和文档无横向溢出；jsdom 不承担 sticky 或像素几何判断。
- 覆盖 1440、375、320、768 和真实 200% 代表场景，并快速复核浅色、深色和跟随系统主题。
- 不扩大截图差异阈值、不增加整卡遮罩、不跳过失败用例。
- 用户移动截图基线当前固化了已知缺陷；先生成候选并人工确认，获得用户批准后才能更新对应自动 snapshot。

### R5. 边界

- 不修改 `backend/`、`contracts/`、数据库、权限、服务端状态、部署配置或业务数据。
- 不新增依赖、第二套设计 Token、基础组件、响应式断点或页面级主题。
- 本任务完成本地实现和验证；提交、推送和预发布部署分别遵守现有确认门禁。

## Acceptance Criteria

- [x] AC1：AI 渠道在 1440×1000 且详情打开时，测试状态与操作控件矩形不相交，表格内容不被固定列遮挡；375px 下横向滚动只发生在 Ant Table 内。
- [x] AC2：用户和平台指标卡在 375px、320px 下，图标与标题、数值均不相交；Dashboard、内容任务、GEO 观测、1440px 和真实 200% 无回归。
- [x] AC3：375px、768px 和真实 200% 下，移动导航、主题及默认 Drawer 关闭按钮均至少 44×44 CSS px；Drawer 仍为 280px，Escape 关闭后焦点正确恢复。
- [x] AC4：代表页面在浅色、深色和跟随系统下保持语义颜色、边界、层级和页面无横向溢出。
- [x] AC5：针对性 Vitest/E2E、前端 typecheck、lint 和 production build 通过；几何检查使用真实浏览器且不依赖预发布写数据。
- [x] AC6：候选视觉经人工确认后才更新受影响 snapshot；未扩大阈值、增加大面积遮罩或更新无关基线。
- [x] AC7：未修改后端、契约、数据库、权限、业务状态、部署配置或运行时依赖。

## Out of Scope

- 创建或伪造内容任务、内容版本及其他预发布验收数据。
- 修复父任务中缺少 `contentVersionId` 的内容审核验收缺口。
- 重构完整表格系统、替换 Ant Design、改变共享壳层构图或重新设计移动信息架构。
- 自动提交、推送、部署或归档任务。

## Risks

- AI 表格缩短最小内容宽度后，真实窄屏仍必须保留固定操作列和内部滚动，不能以“桌面无重叠”牺牲移动可操作性。
- 共享 `MetricTile` 规则会覆盖平台等同源消费者，必须通过真实浏览器验证而不能只检查用户页。
- 44px 目标可能挤压 64px 顶栏或窄屏标题，需在 320px 和 200% 下确认无页面级溢出。
- 用户移动 snapshot 是已知坏基线；实现正确时测试会先失败，未经人工批准不得直接接受新基线。
