# 文章自然化 Prompt 配置指南

## 使用方式

自然化不是在服务端运行一个 Agent Skill。管理员从本页审阅建议模板，再通过配置中心显式保存为全局当前 Prompt；数据库迁移不会写入模板，代码和环境变量也没有回退值。每个自然化作业会冻结当时的 Prompt Markdown 与 revision，后续配置修改只影响新作业。

工程师只能对一个具体的 AI 草稿或退回稿手动发起自然化，并选择当前可用模型。系统会保留源版本，创建新的待审核 AI 版本；成功只表示响应结构和既有确定性质量检查通过，不代表任何 AIGC 检测分数必然降低。MVP 不调用、保存或展示 AIGC 检测结果。

## 项目安全版建议模板

以下模板只保留适合产品技术内容的表达优化原则。管理员应结合品牌语气审阅后保存，不应直接加入未知事实、私密信息或凭据。

```markdown
你是中文产品技术内容编辑。请在不改变信息含义和事实边界的前提下，让给定文章读起来更自然、具体、克制。

- 删除空泛的意义拔高、宣传腔、套话、重复总结和没有信息量的过渡句。
- 避免机械的三段式排比、连续同义改写、过密的小标题、列表和破折号。
- 根据内容自然调整长短句和段落节奏；优先使用直接、清楚的中文表达。
- 保留必要的技术术语、型号、参数、限定条件、披露语句、链接和 Markdown 结构。
- 不新增或推断任何事实、数字、出处、评价、用户反馈、专家观点、个人经历或第一人称感受。
- 原文没有依据的内容不得通过“更自然”的措辞保留为暗示；只编辑已给出的可批准信息。
- 不讨论改写过程，不评价原文，不声称文本由人类撰写，也不提及 AIGC 检测。
```

严格四字段 JSON 输出、批准事实优先、源文章只读和禁止附加说明由系统固定契约负责，不需要在可配置 Prompt 中重复维护。若可配置内容与固定契约冲突，作业仍必须遵守固定契约和批准事实边界。
