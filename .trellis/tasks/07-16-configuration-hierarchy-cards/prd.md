# 配置层级与渠道卡片重构

## 目标

把 Prompt 的所有权从平台类型迁移到具体平台，形成“平台类型 → 平台 → 当前 Prompt”的单一权威关系；同时让工程师只选择真正可生成内容的平台，并让管理员在 AI 渠道列表直接看到全部已启用模型。

## 依赖与范围

- 以已提交的 `07-13-configuration-center-navigation` 页面和路由为基线，不恢复旧 Tabs、渠道详情 Modal 或逐渠道模型请求。
- 本子任务是父任务的第一个实施单元，必须先于受约束物理删除和全站中文化完成。
- 同时修改 OpenAPI、数据库迁移、后端和前端；不保留平台类型 Prompt 的旧字段、旧接口或兼容读取。

## 需求

### R1 平台级 Prompt

- 权威关系为 `PlatformType 1-N PlatformProfile 1-0..1 PlatformPrompt`。
- 平台类型保持管理员可维护的动态数据，不改成固定枚举。
- 每个具体平台最多维护一份当前 Prompt；Prompt 是普通 Markdown，管理员保存时覆盖当前内容。
- 配置中心提供三个并列页面：`平台类型`、`平台管理`、`Prompt 管理`。
- `平台类型` 页面只管理分类；`平台管理` 页面管理具体平台及规则版本；`Prompt 管理` 页面按具体平台维护 Markdown Prompt。
- 管理员可直接删除当前 Prompt；平台保留并显示“未配置 Prompt”。

### R2 平台可用性

- 具体平台允许不存在当前有效规则，管理员页面必须继续展示并允许配置。
- 工程师只有在平台同时存在 `ACTIVE` 规则版本和当前 Prompt 时才能选择它创建内容任务。
- 无有效规则时显示“无有效规则”，无 Prompt 时显示“未配置 Prompt”；前端不可选，服务端创建内容任务接口执行相同校验。
- 平台投影和管理流程必须支持不存在 `ACTIVE` 规则的状态；后续删除当前规则时不需要引入替代版本兜底。
- 不为缺失规则或 Prompt 增加默认值、自动选择、历史版本兜底或静默兼容。

### R3 任务关系与作业快照

- 内容任务继续通过所选 `platform_profile_version_id` 锁定具体平台规则，不复制可变 Prompt 正文。
- 每次创建生成作业时读取该平台当时的当前 Prompt，并把具体平台身份、规则身份和最终 system/user message 写入不可变作业快照。
- 管理员后续覆盖或删除 Prompt 不影响已创建作业；尚未创建新作业的任务在 Prompt 缺失时明确失败。
- 新作业必须写入具体平台身份；既有不可变作业允许按已记录的旧快照结构读取。

### R4 数据迁移

- 新迁移直接用 `platform_profile_id` 替换 `platform_prompts.platform_type_id`。
- 旧平台类型 Prompt 复制给该类型下的每个现有具体平台。
- 没有具体平台可归属的旧 Prompt 不保留。
- 迁移后不存在旧列、旧表、双写、双读或第二套 Prompt 类型。

### R5 AI 渠道卡片

- `/ai-channels` 单次响应返回每个渠道的全部已启用模型摘要，只包含显示名和 `model_id`。
- 卡片完整显示全部已启用模型，标签可换行；没有启用模型时显示“暂无启用模型”。
- 前端不得逐渠道请求模型列表，不增加截断、展开、悬浮详情或卡片内模型管理。
- 卡片改善信息层级和响应式表现，但复用现有 Ant Design、主题变量和渠道详情能力。

## 验收标准

- [x] 数据迁移把同一类型的旧 Prompt 复制给该类型全部现有平台，孤立 Prompt 被删除，迁移后只存在平台级 Prompt 所有权。
- [x] 平台类型、平台管理和 Prompt 管理是三个并列导航页面，路由选中态、预取和管理员权限正确。
- [x] 每个平台最多一份可覆盖编辑和物理删除的 Markdown Prompt，不再存在平台类型 Prompt 接口或编辑入口。
- [x] 平台缺少有效规则或 Prompt 时仍可由管理员维护，但不会进入工程师可用平台集合，绕过前端创建任务也会失败。
- [x] 不存在当前有效规则的平台显示“无有效规则”且工程师不可选；激活新规则且 Prompt 存在后重新可选。
- [x] 新生成作业完整冻结具体平台、规则和 Prompt 结果，配置后续变化不影响已有作业，旧作业仍可读取。
- [x] AI 渠道卡片通过一次列表请求显示全部已启用模型的显示名与 `model_id`，空模型、长 ID、移动端和深色主题均正常。
- [x] OpenAPI、FastAPI、前端生成类型、迁移测试、后端测试和前端测试保持一致。

## 非目标

- 不新增 AI 供应商协议、Responses API、模型参数或网络访问能力。
- 不实现固定五种平台类型、`TYPE_BASE` 内容或二阶段生成。
- 不增加 Prompt 版本表、Prompt 模板语法、变量插值或任务级 Prompt 副本。
- 不在本子任务补齐产品、平台、规则版本和平台账号的物理删除；这些由后续子任务负责。
- 不进行全站英文文本扫描；本子任务只处理新页面和改动区域必须使用的中文文本。
