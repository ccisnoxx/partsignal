测量日期：2026-07-12。代码来源：`agent/mvp` 当前工作副本，包含用户未提交主题与视觉改动。

## 条件

- `npm run build` 生产构建，Vite preview 提供 `dist`。
- Chromium 1440×1000，每次使用全新 BrowserContext。
- CDP：延迟 100ms，下行 1,600,000 bit/s（200,000 B/s），上行 750,000 bit/s。
- Mock API 为内存 route fulfill；五次采样最大处理时间 1.20ms。
- 从已可见工作台点击“产品事实”到页面 H1 可见；返回工作台后重复测热路由。

## 已确认判断

- API 和主线程不是当前冷路由主因；冷缓存网络主要等待 StatusTag、TableRegion 和页面块。
- 浏览器首屏会加载约 3.48MB 字体；仅拦截 WOFF2 的反事实测量将冷路由降到约 843ms，说明字体带宽竞争是主要放大因素。
- 当前 Nginx 1.27 Alpine 默认 `gzip` 关闭；主入口对 `Accept-Encoding: gzip` 仍返回 865,755B 且没有缓存头。
