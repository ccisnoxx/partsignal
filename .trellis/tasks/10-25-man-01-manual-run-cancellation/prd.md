# MAN-01 未提交人工运行取消与原因留痕

用户授权仅本地实现和必要定向验证，不接入Browser自动化、不创建平台、不操作线上、不暂存/提交/推送。保留浏览器上传NOT_RUN_NO_EXISTING_PLATFORM及既有任务/证据状态。

- ADMIN/ENGINEER对冻结MANUAL、PENDING、NOT_STARTED且无回答的Run提供显式取消；复用现有cancellable/run_transition与完整批次统计，不提供整批/API/Browser取消。
- 必填非空原因；Run与草稿双CAS，重验当前身份/会话。取消与草稿保存/正式提交锁内互斥；提交先赢则取消409，取消先赢则旧保存/提交409。Profile停用或监测开关关闭不妨碍结束待办。

- 详情展示原因与留痕，页面按服务端CANCEL动作提供入口，复用现有manual-entry一致快照获取Run/草稿版本。背景变化/409显式重读确认，未知结果仅GET核对不重发，主体/卸载/重复提交受控。
