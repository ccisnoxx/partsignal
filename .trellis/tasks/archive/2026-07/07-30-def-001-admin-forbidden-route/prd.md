# 修复 DEF-001 管理员路由无权限空白页

## Goal

统一管理员路由权限边界，为工程师直达受限 URL 提供可访问的 403 页面。

## Requirements

- 管理员路由 `/users`、`/audit`、`/configuration/*` 必须由同一个客户端路由边界保护。
- 工程师直达受限 URL 时保留目标 URL，不挂载受限页面，也不发出对应业务请求。
- 无权限页面必须显示明确的 403 说明和“返回工作台”操作，页面稳定后焦点进入提示区域。
- 侧栏和全局搜索继续隐藏未获权入口；服务端继续作为权限最终权威。
- 移除页面内部重复的重定向或查询门禁，避免审计页 URL 规范化 effect 与重定向竞争。
- 不修改后端权限、OpenAPI、数据库或公开数据模型。

## Acceptance Criteria

- [ ] 管理员可正常进入用户、审计和全部配置路由。
- [ ] 工程师直达三个代表性管理员 URL 时均显示同一 403 页面，URL 保持不变。
- [ ] 403 页面具有可访问名称、`role="alert"`、可见返回按钮和确定的初始焦点。
- [ ] 工程师访问时受限页面未挂载，用户、审计和配置业务请求均未发出。
- [ ] “返回工作台”可由键盘激活并导航到 `/`。
- [ ] 现有管理员导航隐藏、页面壳层、审计页和用户页测试保持通过。
