# 总览页磨砂玻璃视觉改造

## Goal

以用户提供的总览页图片为视觉参考，在不修改后端契约和业务语义的前提下，美化 PartSignal 现有总览页，使管理层能够更清晰地查看核心指标、运营状态、待处理事项和快捷入口。

## Confirmed Facts

- 总览路由是受登录保护的 `/`，当前不附加管理员角色限制；路由、认证和改密门禁必须保持不变，见 `frontend/src/app/App.tsx:39-43`、`frontend/src/app/ProtectedRoute.tsx:8-18`。
- 页面并行读取 `GET /api/v1/dashboard/summary` 与 `GET /api/v1/geo-metrics`，任一请求失败时显示真实错误并允许重试，见 `frontend/src/features/dashboard/DashboardPage.tsx:11-18`、`frontend/src/shared/api/queryOptions.ts:7-17`。
- `DashboardSummary` 只包含待审事实、待审内容、待人工发布、发布需关注和近 30 日准确性问题五个计数，见 `contracts/openapi.yaml:2947-2956`。
- `GeoMetrics` 提供基础 GEO 比率和当前人工文章观测统计；当前总览已展示人工观测、文章结果、已推荐文章、未推荐文章和文章推荐率，见 `contracts/openapi.yaml:2932-2946`、`frontend/src/features/dashboard/DashboardPage.tsx:34-43`。
- 当前用户名称可直接复用已加载的 `/auth/me.display_name`，无需新请求，见 `frontend/src/features/auth/AuthProvider.tsx:20-53`、`contracts/openapi.yaml:1675-1687`。
- `/products`、`/tasks`、`/publications`、`/observations` 是全体已登录用户现有的工作流路由，可作为静态快捷入口；不得新增不存在的创建或详情路由，见 `frontend/src/app/AppLayout.tsx:19-25`、`frontend/src/app/App.tsx:42-53`。
- 项目已有浅色、深色和跟随系统三态主题，玻璃表面、边框、模糊、阴影、状态色和图表色均有语义 Token；不得在页面硬编码主题颜色，见 `frontend/src/app/theme.ts:83-137`、`frontend/src/app/ThemeProvider.tsx:39-109`。
- 全局样式已有玻璃降级、`prefers-reduced-motion`、可见焦点、桌面/移动外壳和 375/768/1024/1440 验收约定，见 `frontend/src/styles/global.css:23-76,199-223,241-291`、`frontend/README.md:25-47`。

## Reference Module Support Matrix

| 参考图模块 | 结论 | 当前真实数据边界 |
|---|---|---|
| 用户问候 | 支持 | 使用当前用户 `display_name`，不生成头像照片、人员身份或团队信息。 |
| 管理层核心指标 | 支持 | 已确认使用人工观测、文章结果、已推荐文章和文章推荐率；只显示接口直接返回值，空比率显示 `—`。 |
| 周期筛选、趋势线、同比/环比 | 不支持 | 接口没有历史序列、上期值或比较结果；不得用单次快照推断趋势。 |
| 运营状态摘要 | 部分支持 | 只能根据摘要接口的五类计数和 GEO 接口的未推荐文章计数表达“正常/需处理”，不得冒充服务健康、AI 渠道健康或发布系统健康。 |
| 待处理事项 | 部分支持 | 可按上述六类真实计数形成分组入口；没有事项明细、负责人、优先级、更新时间或逾期字段。 |
| 近期动态 | 不支持 | 当前总览契约没有事件流、动态数组或时间戳，不拼接其他资源列表伪造动态。 |
| 快捷入口 | 支持 | 仅使用现有四条工作流路由和已有权限边界，不由后端返回虚构配置。 |
| 高优先级提醒 | 部分支持 | 可突出 `publication_attention` 与 `recent_accuracy_errors` 计数，但没有优先级、处理人、时限或详情摘要。 |

## Requirements

- 采用精致的 macOS 磨砂玻璃视觉风格，优化页面信息层级、留白、卡片、状态摘要和待办区域。
- 总览页只保留少量管理层核心指标、运营状态摘要、待处理事项和快捷入口。
- 保持现有浅色、深色和跟随系统主题能力。
- 保持响应式布局和键盘可访问性。
- 保留现有真实 API、权限、路由和业务状态，不改变服务端权威规则。
- 不写死参考图中的数字、人员、近期动态或不存在的业务字段。
- 不新增 Tailwind、shadcn/ui 或第二套组件库；优先复用现有 Ant Design、主题 Token 和共享组件。
- 实施前核对参考图各模块与现有接口的对应关系，明确无法由真实数据支持的内容；只实施无需修改后端契约的视觉改造。
- 顶部只展示人工观测、文章结果、已推荐文章和文章推荐率四个真实 GEO 结果；审核、发布、未推荐文章和准确性问题计数集中到运营状态与待办区域。
- 待办区按真实摘要类别提供计数和现有路由入口，不显示负责人、优先级、更新时间、逾期或其他契约未提供的属性。
- 快捷入口只指向产品事实、内容任务、人工发布和 GEO 观测四条现有路由。

- [x] **AC3**：页面使用真实 `display_name` 提供问候，顶部只展示人工观测、文章结果、已推荐文章和文章推荐率；比率为 `null` 时显示 `—`，不推断趋势或比较。
- [x] **AC4**：运营状态根据待审事实、待审内容、待人工发布、发布需关注、未推荐文章和近 30 日准确性问题计数表达“正常/需处理”，不冒充服务或渠道健康状态。

- [x] **AC6**：快捷入口只指向 `/products`、`/tasks`、`/publications`、`/observations`，所有交互使用原生链接或 Ant Design 控件并可通过键盘访问。
- [x] **AC7**：总览所在外壳、页头、指标卡、状态、待办和快捷入口形成统一的 macOS 磨砂玻璃层级，只消费现有主题 Token，并在不支持 `backdrop-filter` 时回退为可读的不透明表面。
- [x] **AC8**：浅色、深色和跟随系统主题均保持可用，状态不只依赖颜色，焦点可见，并尊重 `prefers-reduced-motion`。
- [ ] **AC9**：375、768、1024、1440px 与 200% 缩放下无页面级横向溢出；核心内容按优先级重排且所有操作可达。
- [x] **AC10**：相关前端单测、全量单测、lint、typecheck 和 build 通过；单测覆盖真实字段映射、空比率、零/非零状态与链接。
- [ ] **AC11**：使用项目 Playwright 流程检查真实登录后页面，覆盖桌面/窄屏、浅色/深色/跟随系统、键盘焦点、控制台与失败请求，并记录结果。

## Out of Scope

- 后端 API、数据库、权限模型和业务状态机变更。
- 新增虚构的人员、近期动态、趋势、日期范围对比或其他现有接口未提供的数据。
- 引入新的 CSS 框架、组件库或与现有主题并行的第二套设计系统。
- 新增日期筛选、图表、近期动态流、待办明细查询、自定义仪表盘或新的权限分支。
