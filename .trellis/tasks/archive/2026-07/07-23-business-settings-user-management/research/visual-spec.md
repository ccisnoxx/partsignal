# 用户管理原型视觉规格

## 证据

- 批准原型：`../artifacts/user-management-prototype-1581x995.png`。
- 原始文件：1581×995、8-bit RGB PNG；任务副本 SHA-256 为 `e33267e40a4f4de470fa0392561df18124065d6f1c82b40635715deaa1e6800b`。
- 原型是已接受视觉与信息架构规格；本任务不使用 ImageGen、不概念化重设计。
- 原型数字、用户名、显示名称、时间和趋势箭头都是视觉样例，不是种子或业务事实。

## 页面网格

- 左侧固定导航约 186px，占视口约 11.8%；主内容从 x≈186 开始，左右内边距约 18–22px。
- 顶部栏约 60px；全局搜索约 424×30px，位于 x≈575–999。
- 标题区约 y=60–125；面包屑在 x≈208、y≈31，新增按钮约 104×32px，位于右上角。
- 五张统计卡位于 y≈134–257，总宽约 1138px；每张约 216×123px，卡间距约 14–16px。
- 主工作区位于 y≈280–985：列表区 x≈204–1252、宽约 1048px；右侧说明栏 x≈1265–1565、宽约 300px；两区间距约 13px。
- 列表筛选区约 88px 高；表格与分页占剩余高度。右栏按“账号类型说明、临时密码说明、重要提示、快捷操作”纵向排列。

## 色彩、表面与字体

- 页面背景为冷白到极淡蓝紫的渐变，近 `#F7F9FF`–`#F2F5FC`；卡片为近白表面，使用细边框、轻阴影和约 8–10px 圆角。
- 主文字近 `#15213D`，次级文字为低饱和蓝灰；主操作近 `#2F2BFF`，成功近 `#16B77A`，危险近 `#EF4D58`，警告近 `#F59E0B`。
- 只使用现有语义 Token 映射近似值，不在页面内硬编码另一套色板。
- 系统中文字体栈，接近 PingFang SC/Inter；标题约 24px，统计数值约 26–28px，正文/表头约 13–14px，辅助文本约 12px。

## 顶部与统计卡

- 页面标题“用户管理”左对齐，说明为“管理内部账号、账号类型、启停状态和临时密码。”；右侧主按钮“新增用户”。
- 卡片图标约 44px 圆形浅色底，使用线性图标；标题、数值、趋势/基线三层垂直排布。
- 五卡顺序锁定为：用户总数、已启用用户、已停用用户、必须修改密码、管理员数量。
- 数值必须取同一服务端响应的实时 summary。由于当前没有趋势权威源，已确认以“暂无历史基线”占据原趋势层级，不渲染虚假箭头或数字。

## 搜索、筛选与表格

- 筛选区搜索框约 200×36px；账号类型与状态选择器各约 112×36px；开关、重置、当前总数和导出按钮保持同一基线。
- 控件顺序锁定：搜索用户名/显示名称 → 账号类型 → 启用状态 → 显示停用账号 → 重置筛选 → 当前总数 → 导出列表。
- 表头约 41px，数据行约 50px，原型首屏可见约 10 行，分页控件明确显示“20 条/页”；实现默认每页 20 条。当前 API 也声明 `page_size=20`，因此首屏可见行数不是页容量。
- 原型列宽近似为：用户名 163、显示名称 145、账号类型 126、状态 119、必须改密 146、创建时间 212、操作 150px。批量选择需要增加 Ant Table 原生选择列，是完成功能所需且原型未清晰展示的最小有意差异。
- 用户名单元格含可访问头像、用户名；头像不使用远程随机图片或 Emoji，可用现有 Token 派生的姓名首字符/账号图标稳定回退。
- ADMIN、ENGINEER、启用/停用、是/否均有文字，不只依赖颜色。
- 行操作使用准确 Ant 线性图标和 Tooltip，约 26–30px 描边按钮；编辑、重置密码、启停和更多的可见/禁用状态必须来自真实能力。

## 分页与右侧说明栏

- 分页区约 70px 高：左侧每页数量，中部页码与前后页，右侧跳页；当前总数来自服务端 `total`。
- 右栏约 300px，卡片间距约 10px；原型四卡高度约 190、156、160、137px，可随真实文案在合理范围自适应。
- “账号类型说明”只展示服务端真实 `ADMIN/ENGINEER`；“临时密码说明”只描述已确认行为；“重要提示”明确无删除、停用保留历史；“快捷操作”连接已选择用户和真实导出。
- 主区页面正常滚动；桌面右栏可在视口内保持可见，内容超出时跟随页面而不是制造双重滚动。移动端按现有响应式规则把右栏移到主列表之后，批量操作仍可访问。

## 交互与状态

- 搜索提交、筛选、开关、重置、分页、每页数量和跳页均写入可恢复 URL；筛选变化重置到第 1 页。
- 表格选择是唯一批量目标来源；切页/筛选后清除不可见选择，避免对用户看不到的旧集合执行操作。
- 启停、批量启停和重置密码使用确认弹窗；失败留在当前上下文，部分失败明确列出账号和服务端原因。
- 新增/编辑/重置表单使用可见 label、Password 控件、提交 loading、字段校验、Escape/取消和焦点归还；关闭后销毁敏感表单状态。
- 加载使用统计 Skeleton 与 Table loading；空筛选结果显示清除条件入口；查询错误使用可重试错误区；403、409 和 `LAST_ADMIN_REQUIRED` 保留服务端准确文案。
- 所有按钮覆盖默认、悬浮、聚焦、禁用、加载状态；键盘可完成筛选、选行、分页、弹窗和主要操作，可见焦点不被移除。

## 响应式与验收视口

- 1581×995 是高保真主视口；桌面内容不得产生页面级横向溢出，表格不足时只在 `TableRegion` 内横向滚动。
- 另验证 1440、1024、768、375px 宽度以及 200% 缩放；原型未定义移动 IA，因此只沿现有 Drawer/堆叠规则确保内容可读、操作可完成、无页面级横向溢出。
- 验证浅色、深色和系统主题，不为贴图而破坏现有主题能力。
- 实施时 Browser 优先；在 1581×995 至少比较导航/顶栏、标题与五卡、筛选与表格、分页与右栏、颜色/图标五组证据，并维护 `artifacts/fidelity-ledger.md`。

## 有依据的保留差异

- 项目没有通知、帮助和应用切换的真实契约；不增加原型中的空图标按钮，保留现有全局搜索、主题和用户区域。
- 原型没有清晰展示批量复选框，但需求明确需要表格选择；采用 Ant Table 原生选择列，不发明悬浮选择、跨页隐式选择或第二种批量交互。
- 原型趋势没有权威数据源；已确认不使用示例箭头和数字，显示“暂无历史基线”。
- 原型动作图标只表达意图；最终 Tooltip、禁用和行为以现有真实命令、最后管理员保护和自助改密约束为准。
