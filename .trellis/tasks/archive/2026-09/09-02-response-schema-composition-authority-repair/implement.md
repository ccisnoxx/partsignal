## 9. 逐 Operation 验收标准

对 `research/allof-authority-defect.md` 列出的每个 operation，必须同时满足：

1. operationId 在 static/runtime OpenAPI 中各出现一次；
2. success response status、media type、Header 和 root schema ref 与 Task 前一致；
3. 经修复 component 引用闭包解析后，真实成功 payload 可被 static/runtime Draft 2020-12 validator 接受；
4. 37-operation success projection 的生产 comparator 总结果为 `[]`；
5. 没有通过 route、service、permission、transaction、状态转换或 error mapping 改动来迁就 schema。

37 个 operation 必须全量测试，不得用“代表路由”抽样替代。精确 operationId 清单只维护在 research 与测试显式常量中；本节不复制第三份长清单。
