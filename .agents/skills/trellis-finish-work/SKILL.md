# 收尾与恢复记录

用已知验收与实际检查区分暂停和完成；必要时运行 `python3 ./.trellis/scripts/get_context.py --mode record` 查看任务状态。不要因为结束会话就归档活动任务。

- 暂停：记录剩余工作、准确资料路径与有效验证，保留可恢复任务。若用户要求解除本会话关联，`task.py finish` 只清指针，不改变任务状态。
- 完成：确认验收与适用门禁满足，再按既有授权提交/归档；未获提交授权时可以交付未提交的修改，保护其他工作。
- 归档：只处理完成且获准的确切任务。其他会话或额外任务不能顺手归档。

调用 `task.py archive`、`add_session.py` 前核对本项目 `--help` 及生命周期 hooks：它们可能自动提交。没有提交授权时使用已提供的禁用提交选项；没有该选项则先准备记录，不借归档隐式提交。只引用实际存在的工作提交，不编造 hash。

需要 journal 时写必要恢复信息和真实验证；无需固定“工作提交→归档提交→日志提交”三段式。最后报告完成项、保留的工作与真实待办。
