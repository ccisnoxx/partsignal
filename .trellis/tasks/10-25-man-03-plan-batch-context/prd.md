# MAN-03 从计划进入建批的上下文衔接

## 目标
计划详情入口传递的plan_id必须成为建批选择的URL身份；不需在列表中重新寻找同一计划。复用计划详情返回的当前矩阵和run命令，不新增API/持久化/权限流程。

## 实现边界
- RunsPage把规范plan_id交给BatchCreate；选择其他计划同步URL，刷新/前进后退恢复正确选择。以plan_id为组件身份，旧读取/回执不能覆盖新页面意图。
- 精确读取计划详情，与列表是否含该计划、列表过滤/分页无关。加载/失败不选其他计划；当前身份或资源不可访问明确说明，支持退出/有恢复可能时重读。
- 展示当前计划名称、revision、服务端矩阵及阻断，创建显式确认。历史或其他CRON不能通过人工建批入口绕过现有MANUAL_ONLY边界。
- 保留既有revision冲突和同幂等键确认未知结果语义；提交中的/未知结果意图受离开保护。成功使用canonical批次ID并保留真实来源plan_id。
- 更新计划入口说明与人工SOP，只进行与此次URL和异步流程相关的定向验证。

## 验收
- [x] 非列表首屏计划深链直接显示正确计划/当前矩阵，无自动写请求。
- [x] URL选择、刷新、Back/Forward及迟到旧请求行为正确。
- [x] 403/404/暂时读取失败、CRON与409重读、未知结果同键恢复保持正确。
- [x] 现有API创建请求及成功批次导航保持一致，定向检查通过。

## 授权边界
保留浏览器上传NOT_RUN_NO_EXISTING_PLATFORM，不接入浏览器自动化、不创建真实平台、不操作线上、不提交推送、不新增自动跟进。不实施MAN-04～06。
