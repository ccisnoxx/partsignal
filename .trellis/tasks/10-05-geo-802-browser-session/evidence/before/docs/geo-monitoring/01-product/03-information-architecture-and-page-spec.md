# PartSignal GEO 信息架构与页面规格

| 项目 | 内容 |
|---|---|
| 文档版本 | V1.0 |
| 文档状态 | 目标设计 |
| 适用前端 | canonical `frontend/` |
| 页面原则 | URL 驱动筛选、服务端读模型、证据可下钻、无前端第二套状态机 |

## 1. 导航结构

最终目标导航如下：

```text
GEO 监测
├─ 总览                      /geo/overview
├─ 问题库                    /geo/questions
├─ 监测计划                  /geo/plans
├─ 运行中心                  /geo/runs
├─ 观测记录                  /geo/observations
├─ 分析洞察                  /geo/insights
├─ 机会与告警                /geo/opportunities
└─ 报告                      /geo/reports

配置中心（管理员）
├─ GEO 平台与采集配置         /configuration/geo-surfaces
├─ 监测对象与竞品             /configuration/geo-entities
└─ GEO 规则与阈值             /configuration/geo-rules
```

### 1.1 兼容现有路由

现有人工文章关系观测和分析洞察路由在迁移期间保留。引入最终 `/geo/*` canonical 路由时必须：

- 使用稳定重定向或导航兼容入口；
- 不在同一发布中同时删除旧路由和数据读取能力；
- 明确区分“文章关系观测”和“回答级观测”；
- 通过单独任务迁移导航和书签，不把路由改名混入数据模型任务。

## 2. 全局页面规则

### 2.1 URL 状态

以下状态必须写入 URL：

- 时间范围；
- 产品/监测对象；
- 问题主题和问题变体；
- AI 观测面；
- 采集方式；
- 语言、地区、登录状态；
- 数据质量状态；
- 页码、每页数量和排序；
- 当前选中的运行、机会或计划 ID。

表单草稿、未提交复核意见和敏感凭据不得写入 URL。

### 2.2 服务端读模型

复杂页面不得由浏览器跨多个列表接口拼接。至少提供以下读模型：

- `GeoOverview`
- `GeoQuestionWorkspace`
- `GeoMonitoringPlanDetail`
- `GeoRunListPage`
- `GeoRunDetail`
- `GeoInsights`
- `GeoOpportunityDetail`
- `GeoReportPreview`

这些模型在服务端统一应用筛选、权限、公式和数据质量规则。

### 2.3 通用状态

每个页面必须具备：

- 首次加载；
- 后台刷新；
- 空数据；
- 部分数据不可用；
- 请求失败；
- revision 冲突；
- 权限不足；
- 资源已删除或已归档；
- 样本不足和不可比提示。

不得把“没有数据”和“请求失败”展示为同一种空状态。

## 3. GEO 总览

### 3.1 页面目标

在不展开底层运行的情况下，让运营人员知道当前监测覆盖、主要变化、风险和待处理工作。

### 3.2 顶部筛选

- 时间范围；
- 产品或产品组；
- 问题意图；
- 观测面；
- 采集方式；
- 语言和地区；
- 点名/非点名；
- 是否仅使用人工已复核数据。

### 3.3 核心卡片

| 卡片 | 展示 |
|---|---|
| 合格运行 | 分子、计划运行、成功率、不可用原因 |
| 自然可见率 | 仅非点名问题，显示分子/分母和前周期变化 |
| 推荐率 | 明确推荐运行数/合格运行数 |
| 自有信源覆盖率 | 有自有引用运行数/有引用合格运行数 |
| 严重错误运行 | 高严重度错误运行数量和未处理数量 |
| 开放机会 | 按高/中/低优先级汇总 |

### 3.4 主体区块

1. 可见率、推荐率、准确率趋势；
2. 重点产品表现；
3. 竞品 SOV；
4. 主要引用域名；
5. 问题覆盖缺口；
6. 严重错误和异常机会；
7. 最近批次和运行失败；
8. 数据质量说明。

### 3.5 行为

- 点击卡片进入带相同筛选的洞察或运行中心；
- 点击产品进入产品 GEO 详情；
- 点击错误进入运行详情对应声明；
- 点击机会进入机会 Drawer；
- 不提供没有服务端能力的“一键优化”按钮。

## 4. 问题库

### 4.1 页面目标

管理规范问题主题和实际运行的文本变体，并明确问题的意图、点名属性、语言、地区和适用对象。

### 4.2 列表字段

- 规范问题；
- 意图；
- 变体数；
- 点名/非点名分布；
- 语言和地区；
- 关联计划数；
- 最近运行时间；
- 当前覆盖状态；
- 可执行动作。

### 4.3 详情工作区

左侧问题主题列表，中间变体表格，右侧用途和运行摘要。

问题变体字段：

- 完整文本；
- 语言；
- 地区；
- `BRANDED/UNBRANDED`；
- 优先级；
- 是否启用；
- 适用产品/对象；
- revision；
- 最近运行和样本状态。

### 4.4 主要操作

- 创建/编辑主题；
- 创建/编辑/启停变体；
- 复制变体形成新文本；
- 查看关联计划；
- 基于变体立即运行；
- 无历史引用时删除；
- 有历史引用时停用，不重写历史。

## 5. 监测计划

### 5.1 页面目标

把问题、观测面、采集配置、监测对象、重复次数和调度规则组合为可预览、可冻结的运行计划。

### 5.2 列表字段

- 计划名称；
- 状态；
- 问题变体数量；
- 采集配置数量；
- 重复次数；
- 单次预计运行数；
- 调度；
- 最近批次；
- 下次计划时间；
- 最近成功率；
- 可执行动作。

### 5.3 编辑器步骤

1. 基本信息；
2. 监测对象；
3. 问题变体；
4. 采集配置；
5. 重复和预算；
6. 调度；
7. 运行矩阵预览；
8. 保存或启用。

### 5.4 运行预览

必须展示：

```text
问题变体数 × 采集配置数 × 重复次数 = 总运行数
```

同时展示：

- API 调用估算；
- 浏览器运行估算；
- 人工待录入数；
- 不支持的能力组合；
- 数据分级或合规阻断；
- 可能使用的 AI 渠道/模型；
- 预计预算上限。

预览由服务端计算，浏览器不得自行推导最终运行数。

### 5.5 状态和动作

| 状态 | 动作 |
|---|---|
| DISABLED | 编辑、预览、启用、立即运行、删除（无历史时） |
| ACTIVE | 查看、暂停、立即运行、创建新配置修订 |
| PAUSED | 编辑、恢复、立即运行、归档 |
| ARCHIVED | 只读、复制为新计划 |

已创建批次使用计划快照，不随计划更新改变。

## 6. 运行中心

### 6.1 页面目标

统一观察批次和单次运行的实时状态、失败、重试、取消和数据质量。

### 6.2 双层视图

- 批次视图：计划、触发方式、运行总数、成功/失败/待人工数量、开始和完成时间；
- 运行视图：问题、平台、采集方式、重复序号、状态、耗时、费用、分析和复核状态。

### 6.3 筛选

- 批次状态；
- 运行状态；
- 计划；
- 产品/对象；
- 问题；
- 平台；
- 采集方式；
- 错误码；
- 时间；
- 是否需要复核。

### 6.4 操作

- 创建立即运行批次；
- 取消未开始批次；
- 对失败运行创建新尝试；
- 打开人工录入；
- 查看原始回答和分析；
- 查看运行环境和快照；
- 不允许修改已完成运行的输入和原始结果。

## 7. 运行详情/观测详情

### 7.1 页面分区

```text
头部：问题、对象、平台、采集方式、状态、时间、请求 ID
左侧：输入和采集环境快照
中间：原始答案、引用和截图
右侧：分析结果、人工复核和关联机会
底部：状态时间线、尝试链、相关任务和复测
```

### 7.2 原始证据

必须展示：

- 完整问题文本；
- 完整答案文本；
- 截图或证据文件；
- 引用 URL、域名、顺序和分类；
- 模型/产品版本；
- 是否发生搜索；
- 采集时间；
- 采集方式和环境；
- 原始 payload 的安全摘要。

### 7.3 分析区

- 自有品牌/产品提及；
- 竞品提及；
- 推荐结论与位置；
- 引用归属；
- 声明列表、事实版本和准确性；
- 分析版本和分析器；
- 置信度和需复核原因。

### 7.4 人工复核

人工可以：

- 确认机器结果；
- 修正对象匹配；
- 修正推荐结论和位置；
- 修正声明准确性和严重度；
- 填写非空理由；
- 生成新分析修订或追加复核记录。

人工不得修改原始答案、引用或截图。

## 8. 观测记录

该页面面向业务浏览，默认只展示 `COMPLETED` 或人工已确认的运行，与运行中心的运维视图区分。

列表字段：

- 观测时间；
- 产品/对象；
- 问题；
- 平台；
- 采集方式；
- 是否提及；
- 是否推荐和位置；
- 竞品数量；
- 自有引用；
- 准确性；
- 人工复核状态；
- 数据质量。

支持从列表直接进入回答详情，不在表格内塞入完整答案。

## 9. 分析洞察

### 9.1 页面目标

在同一筛选口径下展示趋势、竞品、引用、问题覆盖、事实风险和数据质量。

### 9.2 页面区块

1. 指标摘要；
2. 趋势；
3. 产品矩阵；
4. 问题覆盖；
5. 平台表现；
6. 竞品 SOV；
7. 引用域名和 URL；
8. 事实错误类型；
9. 稳定性；
10. 数据质量与排除原因。

### 9.3 指标展示规则

- 每个比率显示分子、分母和样本数；
- 无分母显示“不可计算”，不显示 0%；
- 样本不足显示数值和标签，但不产生趋势结论；
- 点名/非点名默认分栏；
- 不同采集方式默认分栏；
- 所有图表提供可访问表格或明细下钻；
- 公式和阈值只来自服务端。

## 10. 机会与告警

### 10.1 列表字段

- 优先级；
- 规则类型；
- 产品/对象；
- 问题/平台；
- 当前值、阈值、分子和分母；
- 触发时间；
- 状态；
- 关联任务；
- 复测状态；
- 负责人（如后续引入负责人概念）。

### 10.2 Drawer 内容

- 规则和触发依据；
- 来源运行；
- 原始证据；
- 竞品或引用差异；
- 推荐行动类型；
- 关联事实、内容、发布或补测任务；
- 处理记录；
- 复测结果；
- 显式解决或驳回操作。

### 10.3 状态

```text
OPEN → ACKNOWLEDGED → IN_PROGRESS → RESOLVED
                         └────────→ DISMISSED
```

任务完成或复测满足恢复条件均不会自动 `RESOLVED`。进行中的机会可填写原因代码和说明后人工解决，也可在服务端确认所选复测可比且满足冻结恢复规则后，显式确认复测恢复并解决。继续跟进保留 `IN_PROGRESS`，同时记录处理依据和新的 revision。

干预前后比较必须展示两个窗口的指标、分子分母、候选/有效/排除样本和不可判定原因，并列出实际环境、模型版本和采集方式差异。单次变化不得宣称因果关系；样本不足、不可比较或未恢复时仍可继续跟进，人工解决须与复测恢复确认明确区分。

## 11. 报告

### 11.1 报告类型

- 周期 GEO 监测报告；
- 产品专项报告；
- 竞品对比报告；
- 事实风险报告；
- 干预和复测报告；
- 数据质量和运行健康报告。

### 11.2 输出方式

核心版支持：

- 带当前筛选的打印视图；
- 浏览器另存为 PDF；
- CSV 明细导出；
- 报告生成时间、数据截止时间、筛选和公式说明。

不得生成没有数据但标记为成功的空报告。

## 12. 管理配置页

### 12.1 GEO 平台与采集配置

管理员管理：

- AI 观测面；
- 允许的采集模式；
- API 模型绑定；
- 浏览器适配器和会话状态；
- 语言、地区和登录状态；
- 能力标识（引用、搜索、模型版本、费用）；
- 启停和测试状态；
- 合规批准状态。

### 12.2 竞品、别名和域名

管理员管理：

- 自有品牌；
- 自有产品监测身份；
- 竞品品牌和产品；
- 参考型号；
- 别名；
- 自有/竞品域名；
- 父子关系和启停状态。

### 12.3 规则与阈值

管理员管理：

- 最低样本数；
- 趋势下降阈值；
- 竞品突增阈值；
- 严重错误规则；
- 机会去重窗口；
- 复测恢复条件；
- 数据质量门禁。

规则更新只影响后续评估；历史机会保存触发时规则快照。

## 13. 响应式和可访问性

- 主要工作台以桌面高密度布局为主；
- 表格自身横向滚动，页面不产生全局横向滚动；
- 移动端按筛选、摘要、列表、详情顺序堆叠；
- 图表必须有文本和表格替代；
- 状态不能只靠颜色表达；
- Drawer 关闭后焦点返回触发位置；
- 所有关键操作可用键盘完成；
- 运行状态轮询不能导致焦点或滚动位置跳动。

## 14. 页面级验收摘要

| 页面 | 最小验收 |
|---|---|
| 总览 | 所有卡片可下钻；数值有分子/分母；无分母不显示 0 |
| 问题库 | 主题和变体分离；点名属性明确；历史引用下只能停用 |
| 监测计划 | 服务端预览运行数；批次冻结快照；启停不修改历史 |
| 运行中心 | 批次和运行双层状态；失败可显式新建尝试；原运行不变 |
| 运行详情 | 原始答案、引用、截图、分析和复核均可追溯 |
| 洞察 | 同一筛选作用于所有区块；采集方式不静默混合 |
| 机会 | 规则证据完整；可创建任务；任务完成不自动解决 |
| 报告 | 报告显示筛选、截止时间、公式和数据质量 |
