# 前端交互状态与高密度业务组件精修

## Goal

在已完成的 macOS 浅色/深色磨砂一体式工作区和业务布局基础上，精修高密度列表、长表单、审核页面与全站交互状态，使高频信息更易扫描、低频危险操作不抢占注意力、长任务状态清晰可恢复，同时保持现有业务信息架构、字段、操作入口、流程、权限、路由与数据契约不变。

## Confirmed Facts

- `07-16-macos-glass-ui` 与 `07-16-frontend-workspace-layout` 已完成并归档；双主题、全高侧栏、粘性顶栏、内嵌内容画布、集合工作区和详情工作区继续作为本任务基线，不再重做全局框架。
- 2026-07-17 的真实页面审计覆盖登录页、工作台、产品列表、产品事实长表单、内容任务异常态以及 AI 配置浅色/深色页面。审计显示全局视觉已经稳定，下一轮主要问题集中在行操作噪声、长表单定位和保存状态、局部错误恢复、列表状态恢复与浅色主题细节。
- 产品列表以页面内 `search` 状态驱动查询，分页仍由 Table 内部拥有；返回页面后搜索和页码无法由 URL 恢复，见 `frontend/src/features/product-facts/ProductsPage.tsx:19-40`。
- 产品、AI 渠道、平台类型、平台账号等表格持续展示红色删除入口；确认机制已经存在，但低频危险操作与高频详情/维护操作处于同一视觉层级，见 `ProductsPage.tsx:36-40`、`AIChannelsPage.tsx:97-105`。
- 产品事实表单已经有粘性章节导航、`scrollToFirstError` 和粘性保存条，但没有当前章节、章节错误、未保存修改或保存成功状态；动态对象中的删除按钮与字段并列，见 `ProductFactsPage.tsx:116-125`。
- 内容审核已经有章节导航、粘性操作条和宽屏三栏工作区，但导航只提供静态锚点，没有当前章节反馈，见 `ContentEditorPage.tsx:132-173`。
- `QueryFailure`、`QueryLoading` 和 `NoData` 已集中在 `frontend/src/shared/components/AsyncState.tsx`，可复用现有共享边界；当前空态没有上下文操作插槽，错误态只有可选重试。
- 内容任务详情把任务、版本、生成作业和生成选项四个查询共同作为整页门禁，任一次级查询失败都会替换整个详情页，见 `ContentTasksPage.tsx:56-70`。本任务只调整前端呈现和查询分区，不改变服务端错误语义。
- `AppLayout` 已根据路由维护导航选中态，但路由切换后没有把焦点移到主内容；现有 Ant Design `App` Provider 可直接提供主题一致的 `message`，无需新增通知框架或 Provider。
- `ui-ux-pro-max` 建议关注焦点、错误恢复、当前导航、表单错误就近显示、空态、提交反馈和表格响应式；其 Liquid Glass 动态模糊、Web Font、长动效和新视觉配色不适合当前高密度业务后台，本任务不采用。

## Requirements

### P0：列表与长任务核心体验

- **R1 行操作层级**：在高密度集合与配置表格中，每行保留一个明确的详情、维护、审核或编辑主入口；删除、停用等低频或危险操作进入可键盘访问的“更多操作”，继续保留现有权限判断、确认文案、服务端拒绝和加载状态。不得把整行变成第二个隐式导航入口。
- **R2 表格扫读**：数据量较大的集合表格使用现有 Ant Design 能力提供粘性表头、明确的 hover 与 `focus-within` 状态、稳定列宽和长值完整提示；页面级不得横向滚动，宽表仍只由 `TableRegion` 局部滚动。
- **R3 长页面定位**：产品事实、内容审核、内容任务和 AI 渠道等既有章节导航显示当前章节，并以文字或图标加文字标明错误或已修改状态；保持现有章节、字段和文档流，不用 Tabs、Collapse 或内部滚动隐藏业务内容、证据或历史。
- **R4 长表单反馈**：产品事实和其他长期停留、显式保存的编辑区明确显示“已保存”“有未保存修改”“保存中”“保存失败”；提交失败后提供可操作的错误摘要并定位首个无效字段。继续使用显式保存与修订号校验，不新增自动保存或离开页面拦截流程。
- **R5 动态对象层级**：产品事实中的参考型号、证据、参数、替代关系和声明按对象显示简短序号/摘要头，删除入口移动到对象标题区并降低默认视觉强调；字段集合、顺序、默认值、验证规则和提交结构保持不变。

### P1：状态恢复、可访问性与双主题一致性

- **R6 异步状态分区**：页面身份所需查询失败时保留页面上下文、返回入口和明确恢复动作；独立次级查询失败只影响所属区块，不得无必要地替换整页。错误码和请求 ID 继续保留为次级诊断信息，只有可重试失败才突出重试。
- **R7 空态与成功反馈**：共享空态允许在确有下一步且当前可见区域没有等价主操作时提供上下文动作；长期保存、删除、启停等留在当前页面的操作使用现有 Ant Design `message` 给出简短成功反馈。不得为每个查询或短暂状态制造通知噪声。
- **R8 集合状态恢复**：以下已有视图状态由 URL 查询参数拥有，刷新、深链接和从详情返回后可恢复：产品搜索与页码、内容任务页码、人工发布当前 Tab/页码、GEO 观测页码、用户“显示停用账号”与页码。无效参数回到既有默认值，不写入第二套本地持久化。
- **R9 焦点与语义**：路由切换后主内容获得程序化焦点且不造成滚动跳动；章节导航对当前项使用 `aria-current`；更多操作、错误摘要、空态动作和表格滚动区具备明确中文可访问名称，键盘顺序与视觉顺序一致。
- **R10 双主题一致性**：浅色、深色和 `system` 模式分别验证正文、次级文字、选中导航、边框、焦点、错误/成功状态和 sticky 表面的可辨识度。只有实测不达标时才调整现有 `theme.ts` 语义 token，不建立页面级颜色补丁。

### P2：工作台信息权重

- **R11 当前指标优先级**：仅基于现有工作台字段和数值调整指标权重；非零待办和异常使用既有 warning/danger 语义，零值与正常指标降低强调。不得新增趋势、预测、历史比较、图表库或后端字段。
- **R12 最小实现边界**：优先复用 React、React Router、Ant Design、TanStack Query、现有主题 token、`TableRegion`、`AsyncState`、章节导航和 CSS；不新增运行时依赖、状态库、页面构建器、通知系统或第二套设计系统。

## Acceptance Criteria

- [x] **AC1**：目标集合表格每行只有一个高频主入口；低频危险操作通过明确的更多菜单到达，原权限、确认、加载、错误处理和服务端约束全部保留。
- [x] **AC2**：产品、内容任务、人工发布、GEO 观测、用户与 AI 配置等长表格表头在页面滚动时可定位；375/768/1024/1440 与 200% 缩放下无页面级横向溢出，宽表仅在 `TableRegion` 内滚动。
- [x] **AC3**：产品事实、内容审核、内容任务和 AI 渠道章节导航能随滚动标示当前章节，并通过 `aria-current` 暴露状态；条件章节不存在死链接，sticky 区不遮挡目标。
- [x] **AC4**：产品事实表单能区分未修改、未保存、保存中、已保存和失败状态；字段验证失败后错误摘要可定位首个错误，章节导航能标示含错误的章节，保存请求与数据结构不变。
- [x] **AC5**：产品事实动态对象拥有可扫描的对象标题和降噪后的删除入口；所有字段、顺序、默认值、验证规则、上传、修订号和提交载荷保持不变，审核证据和历史不被折叠隐藏。
- [x] **AC6**：内容任务等复合详情页面的次级查询失败只在所属区块展示错误和恢复动作；核心详情、返回入口以及其他已成功区块仍可使用。必需查询失败时完整错误页仍包含页面上下文和返回路径。
- [x] **AC7**：目标集合页的搜索、Tab、分页和显示停用账号状态由 URL 恢复；无效查询参数安全回到默认值，浏览器前进/后退不会出现 URL 与 UI 两套状态。
- [x] **AC8**：长期保存、启停和删除成功后有简短、主题一致且不抢焦点的反馈；空态只在没有同屏等价操作时提供下一步，不重复主操作。
- [x] **AC9**：路由切换、章节导航、更多菜单、弹窗关闭和错误恢复通过键盘可操作；焦点可见且顺序合理，浅色/深色关键文字与控件达到 WCAG AA，颜色不是唯一状态信号。
- [x] **AC10**：工作台仍展示原有指标、口径和链接；非零待办/异常比零值更醒目，未新增接口、字段、趋势图或推测数据。
- [x] **AC11**：`npm run api:check`、Lint、类型检查、相关单元测试、全量测试和构建通过；现有 E2E 与真实浏览器矩阵覆盖代表性列表、长表单、内容审核、局部失败和双主题。
- [x] **AC12**：diff 不包含后端、OpenAPI、数据库、部署、运行时依赖、业务路由、权限、状态转换或字段契约变化，也不恢复截图基线。

## Out of Scope

- 第三次全局换肤、重新设计侧栏/顶栏、改变 macOS 玻璃边界或新增品牌视觉。
- 新增、删除、合并或重排业务字段、操作权限、业务步骤、服务端状态转换和 API/数据库契约。
- 自动保存、未保存离开拦截、批量操作、虚拟列表、整行点击、命令面板、拖拽、自定义仪表盘或新的移动业务流程。
- 为没有历史数据的指标新增趋势、预测、同比、环比或装饰性图表。
- 用 Collapse/Tabs 隐藏审核证据、差异、事实、追溯或历史。
- 新的 UI、图标、动画、状态管理、表格、通知或可访问性依赖；恢复 PNG 截图基线或像素回归测试。
