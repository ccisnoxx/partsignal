# Dashboard 与 GEO 洞察视觉统一

## 目标

统一 Dashboard、GEO 观测记录、GEO 分析洞察和打印报告的页面标题、指标卡、信息层级、间距及图表表达，使其遵循现有 PartSignal 视觉系统，并保持全部真实数据、服务端统计口径和业务交互不变。

## 已确认范围

- Dashboard：`/`
- GEO 观测记录：`/observations`
- GEO 分析洞察：`/observations/insights`
- GEO 打印报告：`/observations/insights/print`
- 上述页面实际使用的 `PageHeader`、`MetricTile`、查询状态组件、表格区域和现有自绘图表。

## 需求

1. 页面统一复用现有 `PageHeader`，正常、加载、空数据和错误状态均保留唯一且可见的页面标题。
2. Dashboard 与 GEO 观测的指标卡统一标签、数值、进度、说明和图标的视觉层级；仅展示现有 API 的真实指标，不改变换算和统计口径。
3. GEO 洞察保留自绘 SVG 折线、Ant Design 比率条、二维漏斗、排行和覆盖矩阵，不替换图表库或数据处理逻辑。
4. 图表统一消费 `theme.ts` 已有图表 Token；折线、坐标轴、网格、图例、Tooltip、缺失值、加载、空态和错误态必须清晰且可访问。
5. GEO 观测的筛选 URL、排序、分页、列设置、详情、新建、更正和服务端查询行为保持不变；GEO 洞察全部筛选参数、默认日期范围、数据质量限制和打印参数保持不变。
6. 浅色、深色、跟随系统、窄屏、200% 缩放、键盘操作、图表替代文本和 `prefers-reduced-motion` 均通过真实浏览器检查。
7. 只修改目标页面的作用域样式；不得全局替换主题色、重写 `global.css`、添加视觉依赖或扩散到其他页面。

## 验收标准

- [x] 三个主页面和打印报告均使用 `PageHeader`；加载和错误不再遮蔽页面身份。
- [x] Dashboard 4 项指标、GEO 观测 5 项指标与现有 API 响应逐字段一致，未知值不补零。
- [x] GEO 观测指标加载和失败有显式反馈，记录空态说明当前筛选无结果；375px 下指标图标、标签和数值不重叠。
- [x] GEO 洞察折线为 2px，使用现有 `geoSeries*`、`chartGrid`、`chartAxis`、`chartTooltip*`，并显示纵轴刻度、首末日期和低对比网格。
- [x] 趋势图只占一个 Tab 停靠点，可用 Left/Right/Home/End 浏览数据点；替代文本包含指标、当前值、对比值和日期范围。
- [x] 平台图例只描述实际四个比率系列；比率条与数据质量 Tooltip 支持鼠标和键盘，颜色不是唯一信息载体。
- [x] 320、375、768、1024、1440px 及真实浏览器 200% 缩放下无页面级横向滚动、文字遮挡、焦点丢失或关键操作消失。
- [x] 浅色、深色和跟随系统下正文、边界、状态、图表、Tooltip 和焦点清晰；reduced-motion 下状态理解不依赖动画。
- [x] 目标单测、TypeScript、Lint、构建和目标 Playwright 用例通过。

## 排除项

- 不修改编辑审核工作区、Prompt 管理、认证页面和第一批列表工作台页面。
- 不修改后端、数据库、OpenAPI、生成类型、查询契约、权限和部署配置。
- 不新增 UI、图表、字体、图标或动效依赖。
- 不创建图表工厂、Dashboard 配置系统、通用页面壳层或第二套设计系统。
- 不修改 `theme.ts`，除非实施中出现当前 Token 无法表达且有实测证据的阻塞；该情况必须返回规划阶段，不得自行扩展。

## 风险

- 自绘 SVG 的键盘导航和打印表现是主要交互风险，必须由单测和真实浏览器双重验证。
- `global.css` 是共享文件，所有新增或调整规则必须带目标页面前缀，并通过 Diff 审查防止影响其他页面。
- 增加图表坐标与可读间距会增加 GEO 洞察纵向高度；不得用缩小字体或隐藏真实数据抵消。
