# PartSignal GEO 术语表

## 1. 核心术语

| 术语 | 英文/标识 | 定义 |
|---|---|---|
| GEO | Generative Engine Optimization | 改善品牌、产品和权威内容在生成式搜索或 AI 回答中的发现、提及、推荐、引用和准确性的持续过程。 |
| AEO | Answer Engine Optimization | 面向答案引擎的优化。本文档中与 GEO 视为相邻概念，不单独建设另一套功能。 |
| 监测对象 | Geo Subject | 被识别、比较和聚合的品牌、公司产品、竞品、竞品产品或参考型号。 |
| 自有产品 | Own Product | 关联现有 `Product` 的公司产品监测对象。 |
| 参考型号 | Reference Part | 用户问题中经常出现、需要观察替代关系或比较关系的外部型号。它是 GEO 监测身份，不恢复旧规范化事实子图。 |
| 别名 | Subject Alias | 同一对象可能出现的名称、型号写法、缩写、连字符、大小写或旧称。 |
| 自有域名 | Owned Domain | 公司控制并用于判定自有引用的域名。 |
| 问题主题 | Query Topic | 代表一个稳定用户意图的规范问题，继续复用现有 `QueryTopic`。 |
| 问题变体 | Prompt Variant | 问题主题的一种具体提问文本，包含语言、地区、点名属性和启停状态。 |
| 点名问题 | Branded Prompt | 文本中主动包含公司品牌或产品名称，用于观察品牌认知和事实准确性。 |
| 非点名问题 | Unbranded Prompt | 文本不主动提及公司品牌或产品，用于观察自然可见度和推荐能力。 |
| AI 观测面 | Engine Surface | 用户实际接触或系统实际调用的 AI 产品/API，例如豆包网页、DeepSeek 网页、OpenAI-compatible API。 |
| 采集方式 | Collection Mode | `MANUAL`、`API` 或 `BROWSER`。 |
| 采集配置 | Collection Profile | 某个观测面在指定模式、语言、地区、登录状态、模型和适配器下的一组可运行配置。 |
| 监测计划 | Monitoring Plan | 选择问题变体、采集配置、监测对象、重复次数和调度策略的可变配置。 |
| 运行矩阵 | Run Matrix | 问题变体 × 采集配置 × 重复次数形成的单次运行集合。 |
| 观测批次 | Observation Batch | 一次冻结的监测执行，保存计划快照、触发方式和全部运行。 |
| 单次运行 | Observation Run | 一个问题变体在一个采集配置下的一次独立观测。 |
| 尝试 | Run Attempt | 对失败运行进行显式重试时创建的新运行尝试。原运行保持不可变。 |
| 原始答案 | Answer Snapshot | 采集到的完整回答正文、原始载荷摘要、模型信息、搜索状态和采集时间。 |
| 引用 | Citation | AI 回答中明确展示或结构化返回的 URL、域名和位置。 |
| 提及 | Mention | 回答文本中识别到某个监测对象的名称或别名。 |
| 推荐 | Recommendation | 回答对某个对象给出明确选择、推荐、优先级或候选位置。单纯列举不一定构成推荐。 |
| 推荐位置 | Recommendation Rank | 在具有明确顺序的推荐列表中的序位。没有可靠顺序时必须为空。 |
| 声量份额 | Share of Voice, SOV | 指定对象在自有对象和受监测竞品之间的提及或推荐占比。必须明确使用“运行数”还是“事件数”作为分母。核心版默认使用运行级 SOV。 |
| 声明 | Claim | 回答中关于产品参数、封装、认证、用途、替代关系或其他可核验事实的陈述。 |
| 声明评估 | Claim Assessment | 将声明与绑定的已批准事实版本比较后得到的 `ACCURATE/PARTIAL/INCORRECT/UNJUDGEABLE` 结论。 |
| 分析版本 | Analysis Revision | 对同一原始答案执行的一次不可变机器分析结果。 |
| 人工复核 | Human Review | 人工对机器分析进行确认或修正的追加记录，不修改原始答案。 |
| 合格运行 | Eligible Run | 满足指标所需状态、采集环境和数据质量条件，可进入指定指标分母的运行。 |
| 数据单元 | Metric Cell | 由产品/对象、问题、平台、采集方式、语言、地区、登录状态和时间范围定义的可比较数据集合。 |
| 稳定性 | Stability | 同一数据单元内重复运行得出一致提及或推荐结果的程度。 |
| 机会 | Opportunity | 由确定性规则从趋势、错误、竞品或数据质量中识别出的待处理业务问题。 |
| 干预 | Intervention | 为改善某个机会而完成的事实修订、内容任务、发布修复或渠道行动。 |
| 复测 | Retest | 基于冻结基线和同口径配置执行的新批次，用于比较干预前后的相关变化。 |
| 文章关系观测 | Article Observation | 现有 `MANUAL_ARTICLE_SEARCH` 模型：人工检查已发布文章在搜索结果中的发现、提及、推荐、引用和准确性。 |
| 回答级观测 | Answer Observation | 本次新增模型：以完整 AI 回答为中心分析品牌、产品、竞品、引用和声明。 |

## 2. 指标用语

| 用语 | 规则 |
|---|---|
| 可见 | 指定对象至少被提及一次。 |
| 推荐 | 存在明确推荐结论，不能仅由名称出现推断。 |
| 首位推荐 | 推荐列表具有可靠顺序且对象排名为 1。 |
| 自有引用 | 引用 URL 的规范化域名属于已配置自有域名。 |
| 竞品运行 | 回答至少提及或推荐一个受监测竞品。 |
| 严重错误 | 对安全、认证、关键参数、替代边界或产品身份产生高业务风险的错误声明。 |
| 无分母 | 指标返回 `NULL`，不得返回 0。 |
| 样本不足 | 分母大于 0 但低于该指标最低样本，展示结果和样本但不得触发趋势型机会。 |
| 不可比 | 语言、地区、采集方式、登录状态、问题版本或平台身份不同，除非用户显式选择聚合且指标文档允许。 |

## 3. 状态用语

| 用语 | 含义 |
|---|---|
| 不可变 | 记录不能原地修改；修正通过新版本、追加记录或显式删除命令完成。 |
| 当前版本 | 聚合上唯一指向的最新有效版本，不表示历史被覆盖。 |
| 主线 | 服务端维护的唯一当前业务版本指针。 |
| 快照 | 创建时冻结、后续不随配置变化的输入或结果。 |
| 门禁 | 不满足条件时必须明确失败，禁止自动回退或伪造成功。 |
| 补投递 | 外部调用尚未开始的 `PENDING` 工作因消息丢失而重新发送仅含 ID 的队列消息。 |
| 重试 | 由用户或规则显式创建新尝试；已经发送外部请求的原尝试不得自动再次调用。 |
