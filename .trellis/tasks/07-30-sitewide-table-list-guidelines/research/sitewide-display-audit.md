# 全站 24 张业务表展示审计

## 审计口径

- 基线沿用归档任务 `07-30-management-list-hard-delete-ux` 的 24 张业务表，并与 `cross-page-visual-convergence.spec.ts` 的当前显式清单逐项核对。
- 每张表按“主身份 / 辅助信息 / 状态或指标 / 时间 / 操作”判断列角色；没有业务意义的角色不强行补列。
- 长文本只有在子元素可收缩、行高有界，且完整原值能由 hover 与键盘 focus 读取时才算通过。
- 已有搜索、筛选、排序、结果数量、列设置、批量操作和分页只检查视觉层级，不改变请求参数或新增能力。
- `TableRegion` 继续只持有语义与外层边界，横向滚动由现有 Ant Table 或 GEO 原生矩阵持有。

## 共享结论

1. 不创建列配置中心、通用工具栏或新的 Tooltip 文本组件；现有页面列定义仍是唯一所有者。
2. `.table-cell-ellipsis` 同时标记普通和交互长文本，并补 `min-width:0`，让全站 58 个文本槽都进入同一收缩与回归合同。
3. 跨页 E2E 对普通 `td` 和动态矩阵 `th` 内可见的 `.table-cell-ellipsis` 注入边界长文本，检查文本仍被单元格包含、确实发生省略、键盘可达且行高不增长。
4. GEO 使用独立 GET route fixture 接近 `search_platform` 160 字符上限，精确检查相邻列几何、52px 行高和 hover/focus Tooltip。
5. 不调整搜索、筛选、排序、分页、响应合同、权限或数据来源。
